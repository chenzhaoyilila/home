Write

Only you can publish from here.

Notes you write here are saved straight to your GitHub repository and appear on the site about a minute later. GitHub only accepts a save that comes with a key from your account, so anyone else who opens this page can look, but can't change anything.

  1. 01
    Create a key on GitHub

    The link opens GitHub's form with the name and permission filled in. Under Repository access, choose Only select repositories → home. Check that Contents says Read and write, then click Generate token and copy the key.

    Open GitHub
  2. 02

The key stays in this browser and is only ever sent to GitHub. Never put it in a file, a message or a chat. You can revoke it at any time on GitHub (Settings → Developer settings → Personal access tokens).
